# Design Documentation & Artifacts

This directory contains design references and visual review assets for the Quiz monorepo.

## Contents

- UI references and mockups
- Approved screenshots
- Visual review notes
- Design-system decisions

## Governance & Rules

- **Storage discipline**: Temporary browser captures do not belong here automatically. Only useful, explicitly reviewed artifacts should be committed here.
- **Temporary files**: Generated temporary files belong in ignored temporary storage outside tracked source directories.
- **Precedence**: Design documents are not authoritative for product behavior. If design assets or documentation conflict with product rules in `docs/product/`, the product documentation remains authoritative.
